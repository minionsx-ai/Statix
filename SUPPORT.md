# Support

Statix is maintained as an open source tool project.

## Questions

Use GitHub Discussions if enabled. Otherwise, open an issue with the `question`
label.

## Build failures

Open a bug report and include:

- host OS and CPU architecture
- Docker or compatible runtime version
- target triple
- Rust project or crate being built
- full failing command
- relevant error output as text

## Security issues

Do not report vulnerabilities in public issues. See [SECURITY.md](SECURITY.md).
